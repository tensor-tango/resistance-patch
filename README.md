Working Right-Stick Camera/ analog camera plugin for Resistance Retribution for PPSSPP emulator.

Specififically for US version of the game UCUS98668.

Just unpack the archive, insert an unpacked folder called "resistance_remastered_ppsspp", with $plugun.ini$ and $resistance_remastered.prx$ into "PLUGINS", so the whole path look like this

...\PPSSPP\PSP\PLUGINS\resistance_remastered_ppsspp

Map right analog stick in "Extenden PSP Control"
